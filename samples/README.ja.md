# チュートリアル用サンプルデータ

`seg-studio-tutorial.zip` — SIM カード接点部のマクロ写真 38 枚と、そのアノテーションマスクです。インポートすれば、自分の画像を用意しなくても 1 分ほどで動くプロジェクトが手に入ります。

操作を覚えたいときと、自分のデータで結果が出ないときに「ソフトの設定が悪いのか」「データがまだ整っていないのか」を切り分けたいときに使ってください。

## インポート

プロジェクト タブ → **インポート** → この ZIP を選択。ファイル名からプロジェクトが作られ、画像とマスクが一緒に読み込まれます。

## 中身

| | |
|---|---|
| 画像 | 38 枚、512x512、JPEG (品質 95、4:4:4 = 色差間引きなし) |
| マスク | 38 枚、PNG、クラス 1 つ (`class1`) |
| 欠陥あり | 22 枚 |
| 正常確認済み | 16 枚 (マスクが全面背景 = **Mark Clean** が書く状態) |

欠陥は金メッキパッド上の小さな黒い点や細かいキズで、意図的に簡単ではありません。数画素の欠陥こそこのツールが存在する理由であって、分かりやすい塊だけで動くチュートリアルは間違ったことを教えてしまいます。

正常 16 枚も意図的に入っています。マスクが全くない画像は「未確認」—— まだ誰も見ていない状態です。Mark Clean した画像は「欠陥がないと確認された」状態で、モデルはそこから学習します。この 2 つは別物で、その違いは見た目以上に効いてきます。
