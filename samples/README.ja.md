# チュートリアル用サンプルデータ

`seg-studio-tutorial.zip` には、SIM カードの接点部分を撮ったマクロ写真38枚と、そのアノテーションマスクが入っています。インポートすれば、自分の画像を用意しなくても、1分ほどで動くプロジェクトができあがります。

操作を覚えたいときに使ってください。また、自分のデータでうまく結果が出ないときに、原因が「ソフトウェアの設定」にあるのか、「データがまだ整っていないこと」にあるのかを切り分けるのにも使えます。

## インポート

プロジェクトタブ → **インポート** → この ZIP を選びます。ファイル名からプロジェクトが作られ、画像とマスクがまとめて読み込まれます。

## 中身

| | |
|---|---|
| 画像 | 38枚、512x512、JPEG（品質95、4:4:4。色差の間引きなし） |
| マスク | 38枚、PNG、クラスは1つ（`class1`） |
| 欠陥あり | 22枚 |
| 正常確認済み | 16枚（マスクが全面背景で、`metadata.json` に確認済みの印がある状態。**Mark Clean** で記録されるのと同じ状態） |

欠陥は、金メッキのパッドに付いた小さな黒い点や細かい傷です。あえて簡単なものにはしていません。数ピクセルほどの欠陥こそ、このツールが想定している対象です。分かりやすい大きな塊でしか動かないチュートリアルでは、間違ったことを教えてしまいます。

正常な画像16枚も、意図して入れています。マスクがまったく無い画像は「未確認」、つまりまだ誰も見ていない状態です。Mark Clean した画像は「欠陥が無いと確認された」状態で、モデルはそこから学習します。この2つは別の状態で、その違いは見た目以上に結果を左右します。

プロジェクトの作者が、自分の機材で自分の部品を撮影したものです。顧客の素材や第三者のデータは含みません。リポジトリのほかの部分と同じライセンス（Apache-2.0）で配布しています。
