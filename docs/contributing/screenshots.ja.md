# ハンドブック用スクリーンショット撮影リスト

ハンドブック（`docs/ja/handbook.md`）に入れる図の撮影指示です。もとはハンドブックの本文に HTML コメントとして埋め込まれていましたが、公開ドキュメントのソースを読む人には未完成に見えるため、こちらへ移しました。

撮影したら `docs/images/` に置き、ハンドブックの該当箇所に通常の Markdown の画像として貼ってください。ファイル名は、各項目の `[...]` に書かれているものを使います。

## 第1章「ようこそ」
- 撮影：プロジェクトタブを開いた直後の画面。上部のタブバー全体（プロジェクト / ラベル / 学習 / ライブ検査）が1枚に収まるよう、横幅を広めにとる。「外観検査デモ」プロジェクトが一覧に入っているとよい。

## 第2章「起動と画面構成」

## 第4章「画像を入れる」

- 撮影：動画ファイルをドラッグ＆ドロップした直後に表示される、フレーム間隔（interval）を尋ねるダイアログ。N フレームごとに抽出するための数値の入力欄が見える構図。

## 第6章「アノテーションする」

- 図（スクリーンショット未収録）：SAM マーキングの結果 [06b_sam.png]
- 撮影：SAM ツールを選び、欠陥をクリックしたあとの確定前のプレビュー。クリックした点（緑の +）と、SAM が提案したマスクのハイライトが見える状態。Enter で確定する直前の、見栄えのよい瞬間。
- 図（スクリーンショット未収録）：ひび割れ検出の自動トレース [06c_crack_spot.png]
- 撮影：ひび割れ検出ツールで、ひび割れの両端の2点をクリックして自動でトレースされた結果。または、スポット検出で点状の欠陥が検出された様子。
- 図（スクリーンショット未収録）：AI サポートパネル [06e_ai_support.png]
