# ハンドブック用スクリーンショット撮影リスト

ハンドブック (`docs/ja/handbook.md`) に入れる図の撮影指示です。もとは
ハンドブック本文に HTML コメントとして埋め込まれていましたが、公開ドキュメントの
ソースを読む人には未完成に見えるため、こちらへ移しました。

撮影したら `docs/images/` に置き、ハンドブックの該当箇所に通常の Markdown 画像
として貼ってください。ファイル名は各項目の `[...]` に書かれているものを使います。
