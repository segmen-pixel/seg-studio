# はじめてのファーストラン手順

Seg-Studio は、工場の外観検査向けに作られたセマンティックセグメンテーションツールです。このガイドでは、アプリを開いてから最初の AI 予測を確認するまでの一連の流れを、約 10 分でひととおり体験します。

機械学習の経験は不要です。手順に沿って進めてください。

> 英語版: [../first-run-manual.md](../first-run-manual.md)

---

## 始める前に

用意するものは 2 つです。

1. **Seg-Studio サーバーが起動していること** — お使いのマシン（またはネットワーク上のマシン）でサーバーが動いていて、ブラウザで `http://localhost:8002/ui/` にアクセスできる状態にしてください。
2. **テスト画像を数枚** — 検査したい部品の写真を 5〜10 枚。標準的な形式（PNG、JPEG）で問題ありません。

サーバーのセットアップを別の方に任せている場合は、URL を確認するだけで先に進めます。

---

## 手順 1: Seg-Studio を開く（30 秒）

ブラウザで次の URL を開きます。

```
http://localhost:8002/ui/
```

上部に **プロジェクト**・**ラベル**・**学習**・**ライブ検査** の 4 つのタブが並んだヘッダーが表示されます。最初は「プロジェクト」タブが選択されています。

> **ヒント:** ページが読み込めない場合は、サーバーが起動していない可能性が高いです。セットアップ担当の方に確認するか、サーバーを起動したターミナルを確認してください。

---

## 手順 2: 最初のプロジェクトを作る（1 分）

プロジェクトは、1 つの検査タスクに使う画像・ラベル・学習済みモデルをまとめて管理する単位です。

1. テキスト欄に名前を入力します。`表面キズ検査` や `はんだ付け確認` のように内容が分かる名前がおすすめです。
2. **プロジェクト作成** をクリックします。
3. プロジェクトのカードが表示され、自動的に選択されます。

これで、画像を受け入れる作業スペースの準備ができました。

---

## 手順 3: テスト画像をアップロードする（1 分）

1. 上部の **ラベル** タブをクリックします（英語表示のときは Annotate と表示されます）。
2. 左の画像パネルにある **＋** ボタンをクリックするか、画像ファイルをパネルに直接ドラッグ＆ドロップします。
3. アップロードの進捗が終わるまで待ちます。
4. 任意のサムネイルをクリックすると、キャンバスにその画像が読み込まれます。

画面中央に画像が表示され、右側にクラス一覧が出ていれば成功です。

---

## 手順 4: 数枚にラベルを付ける（3 分）

ここが、AI に「何を探すか」を教える工程です。欠陥の部分を塗ることで、モデルがそのパターンを学習します。

1. **クラスを作る** — 右パネルの **クラス追加** をクリックし、`キズ` や `割れ` のような名前を付けます。これが欠陥のカテゴリになります。
2. **ブラシツールを選ぶ** — キーボードの **B** を押すか、ツールバーのブラシアイコンをクリックします。
3. **欠陥を塗る** — 画像上でクリック＆ドラッグして欠陥部分を塗ります。
   - **[** と **]** でブラシを小さく／大きくできます。
   - 間違えたら **E** で消しゴムに切り替えます。
4. **次の画像へ** — 左パネルで別のサムネイルをクリックします。画像を切り替えると作業内容は自動保存されます。
5. 少なくとも 3 枚で **繰り返します**。ラベルを付ける画像が多いほど、結果は良くなります。

> **ヒント:** より速くラベル付けするには **SAM クリックツール**（**S** キー）を試してください。欠陥を左クリックすると、AI がその輪郭を自動で選択しようとします。Enter で確定、Esc で取り消しです。

---

## 手順 5: 最初のモデルを学習する（2〜5 分）

付けたラベルから AI に学習させます。

1. 上部の **学習** タブをクリックします。
2. 学習モードを選びます。最初は **通常学習** を選んでください。**学習開始** ボタンは、モードを選ぶまで押せません。
3. **学習開始** をクリックします。最初の実行では既定の設定で十分なので、何も変更する必要はありません。
4. **損失（loss）グラフ** を見てください。線が下がっていけば、モデルが学習できている合図です。
5. モデルの改善が止まると学習は自動で終了します。数枚の短い実行なら、通常 2〜5 分で完了します。

> **メモ:** 学習開始ボタンが押せないときは、まず学習モードを選んでください。有用な結果を得るには、少なくとも 1 クラスを塗ったラベル付き画像が 3 枚以上あることも必要です。

---

## 手順 6: 結果を確認する

学習が終わると、タブバーに新しい **結果タブ** が表示されます。

1. 結果タブをクリックして開きます。
2. **推論実行** をクリックすると、画像に対する予測が生成されます。
3. 左パネルで画像を切り替えて確認します。各画像で次が表示されます。
   - AI の予測オーバーレイ（色付きの領域）
   - 信頼度スコア

予測を、自分が付けた元のラベルと見比べてください。数枚だけの最初の実行では、AI が欠陥を見逃したり塗りすぎたりするのは普通のことです。

---

## 次のステップ

- **画像を増やして再学習する。** ラベル付き画像が 10〜20 枚以上あると精度が大きく向上します。モデルが間違えた画像を重点的に増やしましょう。
- **別のツール** で素早くラベル付けする：
  - **ワンド**（**W** キー） — 似た色の領域を自動選択します。
  - **SAM クリック**（**S** キー） — クリックするだけで AI が選択を補助します。
- **モデルをエクスポート** — ONNX または CoreML 形式で書き出し、検査装置へ展開できます。

---

## 簡易トラブルシューティング

| 症状 | 確認すること |
|---|---|
| ページが開かない | サーバーは起動していますか。`http://localhost:8002/ui/` を再度開いてみてください。 |
| 学習が始まらない | まず学習モード（例：通常学習）を選び、次にラベル付き画像があるか確認してください。 |
| 結果がよくない | 画像を増やして再学習してください。ラベル付き画像は 10 枚以上を推奨します。 |
| 全体的に動作が遅い | 別の学習実行や重い処理が GPU を使っていないか確認してください。 |
| 画像アップロードに失敗する | ファイルが PNG または JPEG で、壊れていないか確認してください。 |

---

## キーボードショートカット一覧

| キー | 動作 |
|---|---|
| **B** | ブラシツール |
| **E** | 消しゴムツール |
| **S** | SAM クリックツール |
| **W** | ワンドツール |
| **D** | スポット検出ツール |
| **[** / **]** | ブラシを縮小／拡大 |
| **Enter** | 確定（SAM / スポット検出） |
| **Esc** | 現在の操作を取り消し |
| **Ctrl+Z** | 元に戻す |

---

以上が、アップロード → ラベル → 学習 → 確認、という一連の流れです。このサイクルを繰り返すたびにモデルは良くなります。まずは簡単に始め、繰り返しながら、結果を見て次にラベルを付ける場所を決めていきましょう。
