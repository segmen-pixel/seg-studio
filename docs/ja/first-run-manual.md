# はじめてのファーストラン手順

> **この文書の位置づけ**：サーバーが起動している状態から最初の推論結果までを、6つのステップでたどる最短の手順書です。インストールの手順は [README の「試してみる」](../../README.ja.md#試してみる)、機能ごとの説明は[ユーザーガイド](user-guide.md)、サンプルデータを使って同じ流れを詳しくたどる手順は[ハンドブック](handbook.md)をご覧ください。

Seg-Studio は、工場の外観検査向けに作られたセマンティックセグメンテーションのツールです。画像の中の欠陥の場所をピクセル単位で塗り分けられるよう、AI に教えます。このガイドでは、アプリを開いてから、最初の AI の予測（AI が自分で画像に印を付けた結果）を確認するまでの一連の流れを体験します。NVIDIA GPU（グラフィックボード）を搭載したマシンなら、約10分で終わります。

機械学習の経験は要りません。手順どおりに進めてください。

> 英語版：[../first-run-manual.md](../first-run-manual.md)
>
> **前提**：手順1の前に、Seg-Studio のインストールとサーバーの起動を済ませておく必要があります。まだの場合は、先に [README の「試してみる」](../../README.ja.md#試してみる) の手順でインストールしてから、ここに戻ってきてください。

---

## 始める前に

用意するものは2つです。

1. **Seg-Studio のサーバーが起動していること**：サーバーは、Seg-Studio の裏側で動いている部分です。スタートメニュー（Windows）または `~/Applications`（macOS）の **Seg-Studio** を開くと起動します（`start-windows.bat` / `bash start-macos.sh` でも起動できます）。お使いのマシン（またはネットワーク上のマシン）でサーバーが動いていて、ブラウザで `http://localhost:8002/ui/` を開ける状態にしてください。
2. **テスト画像を数枚**：検査したい部品の写真を5〜10枚用意します。一般的な形式（PNG、JPEG）で問題ありません。

サーバーのセットアップをほかの方に任せている場合は、URL を確認するだけで次に進めます。

---

## 手順1：Seg-Studio を開く（30秒）

ブラウザで次の URL を開きます。

```
http://localhost:8002/ui/
```

上部に**プロジェクト**・**ラベル**・**学習**・**ライブ検査**の4つのタブが並んだヘッダーが表示されます。ブラウザの言語設定にかかわらず、最初は日本語の画面で開きます。英語に切り替えるには、ヘッダーの右端にある **EN** をクリックします。タブが Projects・Annotate・Training・Live Inspect になり、ボタンは日本語に戻すための **JP** に変わります。選んだ言語はブラウザに記憶されます。最初は**プロジェクト**タブが選択されています。

> **ヒント**：ページが表示されない場合は、サーバーが起動していない可能性が高いです。Seg-Studio を起動し直すか、サーバーを起動したターミナル（Seg-Studio の起動時に開いた、黒い画面に文字が表示されるウィンドウ）を確認してください。ほかの方がセットアップした PC を使っている場合は、その方に伝えてください。[トラブルシューティング](troubleshooting.md)もあわせてご覧ください。

---

## 手順2：最初のプロジェクトを作る（1分）

プロジェクトは、1つの検査作業に使う画像・ラベル・学習済みモデルをまとめて管理する単位です。

1. テキスト欄に名前を入力します。`表面キズ検査` や `はんだ付け確認` のように、内容が分かる名前をおすすめします。
2. **プロジェクト作成**をクリックします。
3. プロジェクトのカードが表示され、自動的に選択されます。

これで、画像を入れる作業場所の準備ができました。

---

## 手順3：テスト画像をアップロードする（1分）

1. 上部の**ラベル**タブをクリックします（英語表示のときは Annotate と表示されます）。
2. 左の画像パネルにある **＋** ボタンをクリックするか、画像ファイルをパネルに直接ドラッグ＆ドロップします。
3. アップロードが終わるまで待ちます。
4. サムネイルをどれかクリックすると、その画像がキャンバスに読み込まれます。

画面中央に画像が表示され、右側にクラスの一覧が出ていれば成功です。

---

## 手順4：数枚の画像にラベルを付ける（3分）

ここでは、AI に「何を探すか」を教えます。欠陥の部分を塗ると、モデルがそのパターンを学習します。

1. **クラスを作る**：右パネルの**クラス追加**をクリックし、`キズ` や `割れ` のような名前を付けます。これが欠陥のカテゴリ（欠陥の種類。種類ごとに色が付きます）になります。
2. **ブラシツールを選ぶ**：キーボードの **B** を押すか、ツールバーのブラシアイコンをクリックします。
3. **欠陥を塗る**：画像上でクリック＆ドラッグして、欠陥の部分を塗ります。
   - **[** と **]** で、ブラシを小さく / 大きくできます。
   - 間違えたときは、**E** で消しゴムに切り替えます。
4. **次の画像へ進む**：左パネルで別のサムネイルをクリックします。画像を切り替えると、作業内容は自動で保存されます。
5. **同じ作業を繰り返す**：少なくとも3枚の画像で繰り返します。ラベルを付ける画像が多いほど、結果は良くなります。

> **ヒント**：もっと速くラベルを付けたい場合は、**SAM クリックツール**（**S** キー）を試してください。欠陥を左クリックすると、AI がその輪郭を自動で選択しようとします。Enter で確定、Esc で取り消しです。

---

## 手順5：最初のモデルを学習させる（NVIDIA GPU なら数分）

付けたラベルを使って、AI に学習させます。

1. 上部の**学習**タブをクリックします。
2. 学習モードを選びます。最初は**欠陥検知**を選んでください。モードを選ぶまで、**学習開始**ボタンは押せません。
3. **学習開始**をクリックします。最初の実行では既定の設定で十分なので、何も変更する必要はありません。
4. 進み具合を確認します。**モデル一覧**に、エポックとそこまでの最高 F1 が表示されます。**ログ**パネルには、エポックごとに1行ずつ `loss`（損失）が出ます。損失は、AI の答えが、付けたラベルからまだどれだけずれているかを表す値です。エポックを重ねるにつれて損失が下がっていけば、モデルが学習できている証拠です。
5. モデルの改善が止まると学習は自動で終了するため、所要時間はハードウェアとデータによって変わります。NVIDIA GPU で、このチュートリアルのように小さな画像を数枚だけ学習する場合は、たいてい数分で終わります。画像の枚数が多い、画像が大きい、パッチサイズ（AI が一度に見る画像の切り出しの大きさ）が大きい、ハードウェアが遅い、といった場合は、数十分以上かかることもあります。

> **メモ**：**学習開始**ボタンが押せないときは、まず学習モードを選んでください。また、意味のある結果を得るには、少なくとも1つのクラスを塗った画像が3枚以上必要です。

---

## 手順6：結果を確認する

学習が終わっても、結果タブは自動では開きません。**モデル一覧**で、その学習の行にある**結果を見る**をクリックします（上の概要にある**結果を開く**でも開けます）。タブバーに、その学習の**結果タブ**が開きます。

1. **推論実行**をクリックすると、画像に対する予測が生成されます（AI が見つけた欠陥に印を付けます）。
2. 左パネルで画像を切り替えて確認します。各画像には次の内容が表示されます。
   - AI の予測のオーバーレイ（色付きの領域）
   - 確信度スコア（AI がどれだけ自信を持っているか）

予測を、自分で付けた元のラベルと見比べてください。数枚だけで学習した最初の実行では、AI が欠陥を見逃したり、塗りすぎたりするのはよくあることです。

---

## 次のステップ

- **画像を増やして再学習する。** ラベルを付けた画像が10〜20枚以上あると、精度が大きく向上します。モデルが間違えた画像を重点的に増やしましょう。
- **別のツールを試して、素早くラベルを付ける。**
  - **SAM クリック**（**S** キー）：クリックするだけで、AI が選択を手伝います。
- **見つけるだけでなく、数える。** 1枚の画像に部品が**何個**あるかを知りたい場合は、学習モードで**個数検査**を選びます。描いたマスク（塗ったラベル）をそのまま使うので、新たにラベルを付ける必要はありません。接している物体も1個ずつ分けて数えられます。対象のクラスが写った画像が4枚以上必要です。
- **モデルをエクスポートする。** 結果タブの**学習モデルを出力**から ONNX または CoreML 形式（一般的なモデルファイルの形式）で書き出し、検査装置に展開できます。

## 簡易トラブルシューティング

| 症状 | 確認すること |
|---|---|
| ページが開かない | サーバーが起動しているか確認し、`http://localhost:8002/ui/` をもう一度開いてみてください。詳しくは[トラブルシューティング](troubleshooting.md)をご覧ください。 |
| 学習が始まらない | まず学習モード（例：欠陥検知）を選び、次にラベルを付けた画像があるか確認してください。 |
| 結果がよくない | 画像を増やして再学習してください。ラベルを付けた画像は10〜20枚以上を推奨します。 |
| 全体的に動作が遅い | ほかの学習や重い処理が GPU を使っていないか確認してください。 |
| 画像のアップロードに失敗する | ファイルが対応形式（JPEG、PNG、BMP、TIFF、WebP）であること、壊れていないことを確認してください。 |

## キーボードショートカット一覧

| キー | 動作 |
|---|---|
| **B** | ブラシツール |
| **E** | 消しゴムツール |
| **S** | SAM クリックツール |
| **D** | スポット検出ツール |
| **[** / **]** | ブラシを縮小／拡大 |
| **Enter** | 確定（SAM / スポット検出） |
| **Esc** | 現在の操作を取り消し |
| **Ctrl+Z** | 元に戻す |

---

以上が、アップロード → ラベル付け → 学習 → 確認という一連の流れです。このサイクルを繰り返すたびに、モデルは良くなっていきます。まずは簡単なところから始めて何度か繰り返し、結果を見ながら次にラベルを付ける場所を決めていきましょう。
