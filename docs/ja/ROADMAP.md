## Phase 1: 開発者に届ける (v1.1)

**目標:** ML開発者・研究者がすぐ試せる状態にする。
**期間目安:** 1〜2ヶ月

### パッケージ配布
- [x] `pyproject.toml` 作成 (hatchling ビルド)
- [ ] `pip install seg-studio` で API + CLI がインストールできる
- [ ] エントリポイント: `seg-studio start` でサーバー起動
- [ ] PyPI (TestPyPI → 本番) への公開
- [ ] GitHub Actions で Trusted Publisher 自動公開

### Windows ポータブルパッケージ

Phase 3 から前倒し。ランタイム同梱は既に実現しており、残っているのは実装作業では
ありません。

- [x] 自己完結ビルド — Python 3.11 と CUDA 版 PyTorch を同梱するため、Python も
      git も CUDA Toolkit も事前インストール不要
      (`scripts/build_installer.py --platform win64 --lean`)
- [ ] 同梱 DLL の再配布可否の整理。これが片付くまでバイナリ配布はできません
      (ソース配布には影響しません)
  - NVIDIA: `cusolverMg64_11.dll` と `nvperf_host.dll` が CUDA EULA の
    再配布リストに載っていない
  - libvips: `pyvips-binary` が未 pin のため、同梱した LGPL バイナリに対応する
    ソースのバージョンを特定できない
  - FFmpeg: OpenCV の DLL に静的リンクされており、LGPL-2.1 第 6 条が求めるのは
    ソース提示だけでなく再リンク可能な形での提供
- [ ] 置き場所の確保 — パッケージは約 3 GB で、GitHub Release の添付は
      1 ファイル 2 GiB 未満

### モデル・重みの配布
- [x] Hugging Face Hub のモデルリポジトリ — `segmen-pixel/seg-studio`。
      SAM チェックポイントの配信で稼働中
- [ ] 初回起動時の教師モデル自動ダウンロード機能
- [ ] `.gitignore` に `*.pth`, `*.onnx`, `*.mlmodel` 追加確認
- [ ] ダウンロード進捗表示 (CLI / UI 両対応)

### 開発者体験
- [ ] `seg-studio --demo` でデモデータ付き即起動
- [ ] API ドキュメント (Swagger) の充実
- [x] Contributing ガイドの整備 (`CONTRIBUTING.md`)
- [x] GitHub Issue / PR テンプレートの整備 (`.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`)

## Phase 3: 非エンジニアに届ける (v2.0)

**目標:** ターミナルを一度も開かない体験。農家、医療従事者が自力で使える。
**期間目安:** 3〜6ヶ月

### デスクトップアプリ化

Python ランタイムの同梱は Phase 1 へ移動しました (Windows パッケージが既に自前の
インタプリタを持っています)。ここに残るのはその外側の殻です。

- [ ] 展開フォルダではなく本物のインストーラ
  - Windows: `.exe` インストーラ (NSIS or WiX)
  - macOS: `.dmg` — 署名と公証があって初めて配る意味があります。無いと利用者全員が
    Gatekeeper を手動で解除することになります
- [ ] GPU セットアップウィザード
  - CUDA 利用可否の自動判定
  - CPU モードへのフォールバックと性能上の制約の明示
- [ ] 自動アップデート機構

### UX 改善 (非エンジニア向け)
- [ ] オンボーディングウィザード
  - 「何を検出したいですか？」→ テンプレート提案
  - サンプルプロジェクトで操作を体験
- [ ] 学習パラメータの自動推奨 (現状の auto-tune をさらに簡略化)
  - 「画像をアップ → 学習ボタン → 完了」の3ステップ
  - 詳細設定は「上級者向け」として隠す
- [ ] 日本語 / 英語 以外の多言語対応 (i18n)
- [ ] 学習完了通知 (メール or ブラウザ通知)

**目標:** セグメンテーション以外にも拡張。業界特化テンプレート。
**期間目安:** 6ヶ月〜

### タスク拡張

      ゼロから作るのではなく直接使える形にする作業です。

- [ ] 医療パック: 細胞セグメンテーション、病理画像解析
- [ ] 事前学習済みモデル + サンプルデータ + チュートリアル

### 連携・統合
- [ ] iPad / iPhone アプリ連携強化 (CoreML直接デプロイ)
- [ ] Edge デバイス対応 (Jetson, Raspberry Pi)
- [x] REST API / Python SDK でプログラム連携 (`/v2` ストリーミング推論 API + `packages/seg-sdk`)

## 判断基準: 各 Phase で何を優先するか

| 判断軸 | 優先度 |
|--------|--------|
| **ユーザーが30秒で価値を感じるか** | 最優先 |
| **インストール障壁を下げるか** | 最優先 |
| **既存コードの変更が最小か** | 高 |
| **一人でも実現可能か** | 高 |
| **新しい技術スタックが不要か** | 中 |
