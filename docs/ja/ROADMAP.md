## 判断基準: 各 Phase で何を優先するか

| 判断軸 | 優先度 |
|--------|--------|
| **ユーザーが30秒で価値を感じるか** | 最優先 |
| **インストール障壁を下げるか** | 最優先 |
| **既存コードの変更が最小か** | 高 |
| **一人でも実現可能か** | 高 |
| **新しい技術スタックが不要か** | 中 |
